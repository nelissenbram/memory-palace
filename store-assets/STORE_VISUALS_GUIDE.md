## 2. RAW SCREENSHOTS TO CAPTURE

You need to manually capture these from the live app. For each, navigate to the right screen and take a full-screen screenshot (browser F11 fullscreen, then Win+Shift+S or browser DevTools screenshot).

**Recommended viewport: 1080x1920 (phone portrait) or capture at any size — the script will crop/fit.**

### Shot 1: Exterior
- Go to Palace > 3D view > exterior
- Wait for cinematic flyover to reach the approach angle (villa centered, slightly below)
- Hide all UI if possible (or the script will overlay it)
- Golden hour lighting is automatic

### Shot 2: Entrance Hall
- Enter the palace, let the cinematic look-around finish
- Position camera looking slightly up at columns, doors visible on sides
- Capture when lighting is warm and settled

### Shot 3: Room Interior
- Enter any populated room with 4+ memories
- Best: a room with photos on walls, warm lighting
- Show the memory display types (frames, paintings, screens)

### Shot 4: Family Tree
- Go to Library > Roots wing > Family Tree tab
- Switch to Fan Chart view
- Ensure 4+ generations visible with photos on cards
- Zoom to show the full tree centered

### Shot 5: Kep
- Navigate to /kep page
- Or: show the Kep landing card in Atrium
- Alternative: capture a WhatsApp conversation with Kep (phone screenshot)

### Shot 6: Explore
- Go to /explore
- Make sure there are 4+ published palace cards visible
- Show Trending or Featured tab active
- Scroll to show follow buttons and visitor counts

### Shot 7: Library
- Go to Library view
- Expand one wing (e.g., Roots) to show room cards
- Show the wing sidebar + room bar

### Shot 8: Achievements
- Go to Profile or Achievements panel
- Show 6+ unlocked badges with progress
- If not enough achievements, use a test account with more progress

## 8. COMPETITIVE ADVANTAGES TO HIGHLIGHT

These are features NO competitor (Ancestry, MyHeritage, FamilySearch, Day One, Journey) has:

1. **3D immersive palace** — all competitors are flat UI
2. **WhatsApp memory capture (Kep)** — zero competitors
3. **Family tree + 3D rooms** — genealogy apps don't have 3D
4. **Social palace visiting** — heritage apps are solo
5. **Cinematic walkthroughs** — theatrical, not functional
6. **Themed wing organization** — narrative rooms, not folders

## 10. WHAT NOT TO SHOW

- Onboarding/registration screens
- Settings/preferences
- Loading states or error screens
- Empty rooms (always populate with memories)
- Subscription paywalls or pricing
- Tutorial tooltips
- Small, unreadable text
