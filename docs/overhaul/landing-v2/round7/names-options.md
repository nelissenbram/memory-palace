# Landing v2 — Round 7: Feature Name Options

Brand lead selection table. For each of the 12 features: a plain description, then 6 curated name options (each with kind + note). The recommended pick per feature is marked with a star (★).

Rules applied: max 2 words, clarity-first (68-year-old test), no ambiguous coinages.

---

## 1. Uploads

**Feature:** Add photos, videos, audio and documents from your device, and auto-sync from your cloud.

| Pick | Option | Kind | Note |
|:----:|--------|------|------|
| ★ | Add Memories | warm | Overwhelming army favorite; warm, clear, on-brand |
|  | Upload | plain | Plainest, universally understood; slight non-EN translation risk |
|  | Add Photos | plain | Concrete and clear; but undersells video/audio/docs |
|  | Your Uploads | plain | Signals a place holding what you added |
|  | Add Files | action | Covers all media types; clear, no ambiguity |
|  | Gather Memories | characterful | Gentle character; 'gather' may complicate translation |
