## 1. Executive Summary & Winning Vision

### 1.1 The verdict

**Winner: "La Sala degli Sguardi — Every Sightline Ends in a Memory" — score 91/100, confirmed by the meta-judge.**

The entrance hall today is an architecture demo with zero real artwork: the Ancestral Wall is disabled (`AW_ENABLED=false`), the focus controller is a dead state machine with no possible target, the "portrait" is a face smeared on a sphere, and the brightest pixel in the room is a fake sky-blue portal (`#87CEEB` at `EntranceHallScene.tsx:2260`) — a triple canon violation for a product whose dogma is "memories = brightest pixels."

**La Sala degli Sguardi inverts the hall's priorities.** Architecture becomes the dark, quiet frame (baked-AO GLB shell, lightmapped, deliberately 0.5-0.7 luminance) and the visitor's photos become the only things allowed to burn. Every one of the five natural sightlines — spawn look-at, impluvium look-down, dome look-up, the seven door axes, and the look-back at the exit — is re-choreographed to terminate on a memory surface: the reborn Ancestral Wall aedicula lit by a tilted real-sun shaft, the visitor's own face in sculpted Carrara doubled in the pool, per-wing memory lunettes over each door, and a golden-hour vista of the world they just left.

Technically it is a discipline wave as much as a beauty wave: retire the w1/w2 flags, collapse ~470 draw calls into GLB heroes so the reclaimed budget is spent on memory surfaces, make the fromScene PMREM bake the single environment authority, and move bloom to a selective HDR threshold of 1.0 so nothing in the hall can bloom EXCEPT deliberately lifted memory picture-lights and sun.

**Why it won over the runners-up (PANINI, LA MERIDIANA, both 90):** they are superior *rendering* visions but they optimize the frame; Sguardi is the only vision whose organizing principle **is the product's own dogma**. A photoreal Pantheon with zero user artwork is still an architecture demo; Sguardi's sightline choreography guarantees every mandatory camera station terminates on user content — the metric a Museum-of-You should be judged by. It also subsumes the discipline work the others open with (flag retirement, light diet, single env authority, selective bloom at HDR 1.0 — the mechanically correct way to enforce "memories brightest").
